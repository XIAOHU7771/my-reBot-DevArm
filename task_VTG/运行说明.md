## 1. 运行前准备

### 1.1 环境

```bash
# 进入仓库根目录（注意：不是 task_VTG/ 里面）
cd <你的仓库路径>/reBot-DevArm   # 或 my-reBot-DevArm

pip install -r requirements.txt
```

依赖：`numpy`、`matplotlib`、`pybullet`（Python ≥ 3.10）。

### 1.2 必须保留的模块

VTG **调用** `task_B2`，不要删：

- `task_B2/2.adaptive_force_control_grasp.py`（力控）
- `task_B2/utils/`（`robot` / `gripper` / `ik`）
- `urdf/00-arm-rs_asm-v3/`（带夹爪 URDF）

### 1.3 两条运行习惯

| 习惯 | 说明 |
|------|------|
| **工作目录 = 仓库根** | 所有命令都从根目录敲 |
| **先 `--direct` 再开 GUI** | `--direct` 无窗口、适合烟测；**去掉 `--direct` 才会弹出 PyBullet 3D 窗口** |

常用可选参数：

- `--direct`：无 GUI（后台算，看不见机械臂）  
- `--no-force-log`：不写力控 CSV/曲线（更快）  
- `--seed N`：随机摆放可复现（M4/M5）  
- `--annotate`：DETECT 后存顶视标注 PNG（M4+M5）

## 1.4 GUI 与可视化（录屏用这个）

VTG 有两层「看得见」的东西，别混：

| 类型 | 怎么开 | 你看到什么 |
|------|--------|------------|
| **PyBullet 3D GUI** | 命令里**不要加** `--direct` | 机械臂、物体、抓取/放置全过程动画 |
| **顶视标注图** | 加 `--annotate`，或跑 `annotate_frame.py` | `debug_images/*.png` 上的检测框与 base 坐标（画面一） |
| **力控曲线** | **不要加** `--no-force-log` | 根目录 `force_data/*.png`（抓完后生成） |

### 开 3D 窗口（主 Demo）

先结束当前带 `--direct` 的进程（终端 Ctrl+C），再运行：

```bash
# 有 GUI + 顶视标注图（推荐录屏）
python task_VTG/scripts/run_pipeline_m4.py --seed 7 --annotate

# 有 GUI，且保存力控曲线
python task_VTG/scripts/run_pipeline_m4.py --seed 7 --annotate
# （上面未写 --no-force-log，会写 force_data）

# 只要相机/场景窗口，不抓取
python task_VTG/scripts/save_camera_frame.py
python task_VTG/scripts/annotate_frame.py --seed 7
```

对比：

```bash
# 无窗口（你现在这种）— 只适合快速验收
python task_VTG/scripts/run_pipeline_m4.py --direct --no-force-log --seed 7 --annotate
```

GUI 模式下窗口会一直开着直到流程结束；结束后提示「关闭 GUI 窗口结束…」，关掉窗口或 Ctrl+C 即可。

**注意**：GUI 比 `--direct` 慢很多；录屏时建议固定 `--seed 7` 方便复现。

## 2. 任务工作流（你在做什么）

一句话：

> **看见（RGB-D）→ 算到基座坐标 → IK 去预抓取 → B2 力控抓紧 → 抬到软/硬放置区。**

```text
┌─────────────────────────────────────────────────────────────┐
│                     一次完整 Demo（推荐 M4）                  │
├─────────────────────────────────────────────────────────────┤
│  1. 连接 PyBullet，加载地面 + 机械臂                          │
│  2. 随机摆放：红色硬块 + 黄色软块（外观染色便于检测）           │
│  3. 臂回到 HOME（减少遮挡）                                   │
│  4. 顶视拍 RGB-D → 颜色检测 → 手眼变换 → (x,y)_base            │
│  5. 对每个物体：预抓取 → 下探 → B2 力控闭合 → 抬升              │
│  6. 按 soft/hard 运到 ZONE_A / ZONE_B，张开放下               │
│  7. 回安全位，处理下一个；打印 PASS/FAIL                      │
└─────────────────────────────────────────────────────────────┘
```

分拣规则（`config.py`）：

| 视觉颜色 | 物理模型 | 类别 | 放置区 |
|----------|----------|------|--------|
| 红 | 铁块 IronBlock | hard | `ZONE_B_HARD` |
| 黄 | 海绵 Sponge | soft | `ZONE_A_SOFT` |

## 3. 代码调用流程（模块怎么串）

### 3.1 全流程（视觉闭环，对应 `run_pipeline_m4.py`）

```text
run_pipeline_m4.py
    │
    ├─ load_robot / init_gripper / init_ik     ← task_B2/utils
    ├─ load_iron_block / load_sponge           ← B2 力控脚本（经 bridge import）
    ├─ 随机采样 xy + 红/黄染色
    │
    └─ pipeline.run_pipeline(source="vision")
            │
            ├─ [DETECT] vision/targets.detect_targets_with_frame
            │       camera.capture_rgbd
            │       detect.detect_colored_cubes   → (u,v,Z)_cam
            │       handeye.cam_to_base           → (x,y,z)_base
            │       （可选）annotate 存 PNG
            │
            ├─ [SELECT] 依次 hard → soft
            │
            ├─ grasp.adaptive_bridge.grasp_and_lift
            │       motion.approach / B2.approach_object
            │       B2.force_controlled_grasp     ← 接触→刚度→F_safe→PID
            │       B2.lift_with_force_hold
            │
            ├─ place_held_object
            │       sort.place_zones → ZONE_A / ZONE_B
            │       B2.move_tcp + open_gripper
            │
            └─ retreat.go_home → 下一物体或 DONE
```

### 3.2 无视觉对照（固定坐标，对应 `run_pipeline_m3.py`）

与上相同，但 `source="config"`：**跳过检测**，物体 xy 写死在 `config.OBJECTS`。用于先验证力控+分拣管道。

### 3.3 重跟踪旁路（对应 `run_retrack_demo.py`）

```text
run_retrack_demo.py
    → grasp_and_lift(enable_retrack=True, nudge_fn=...)
        → motion.approach_with_retrack
              预位 → [NUDGE 平移物体] → tracking.maybe_retrack
              → 更新目标再下降 → 再 force_controlled_grasp
```

不跑完整两区流水线，只验证「下探中物体被挪走仍能改目标再抓」。

## 4. 脚本入口一览

全部在 **`task_VTG/scripts/`**，从**仓库根目录**执行。

| 脚本 | 角色 | 典型命令 | 成功长什么样 |
|------|------|----------|--------------|
| `save_camera_frame.py` | **M1** 只挂相机存图 | `python task_VTG/scripts/save_camera_frame.py --direct` | `debug_images/rgb.png`、`depth.png` |
| `test_detect_localize.py` | **M2** 检测+手眼误差 | `python task_VTG/scripts/test_detect_localize.py --direct` | 打印 `err_xy_cm`，`PASS`；`detect_overlay.png` |
| `run_pipeline_m3.py` | **M3** 固定坐标全流程 | `python task_VTG/scripts/run_pipeline_m3.py --direct --no-force-log` | 两物进两区，`PASS (2/2)` |
| `run_pipeline_m4.py` | **M4** 视觉闭环全流程（主 Demo） | `python task_VTG/scripts/run_pipeline_m4.py --direct --no-force-log --seed 7` | 打印视觉 vs GT；`PASS (2/2)` |
| `annotate_frame.py` | **M5** 只出标注图 | `python task_VTG/scripts/annotate_frame.py --direct --seed 7` | `debug_images/m5_annotate_seed7.png` |
| `run_retrack_demo.py` | **M6** 重跟踪 | `python task_VTG/scripts/run_retrack_demo.py --direct --retrack --nudge --no-force-log` | 日志 `[RETRACK]`，`PASS` |

### 4.1 主 Demo 一条命令（最常用）

```bash
python task_VTG/scripts/run_pipeline_m4.py --direct --no-force-log --seed 7 --annotate
```

- 随机（可复现）摆放 → 视觉定位 → 力控抓取 → 分拣  
- `--annotate`：额外保存标注图到 `task_VTG/debug_images/m5_annotate_seed7.png`  
- 去掉 `--direct`：开 GUI 录屏  

### 4.2 分步验收（排查用）

```bash
# ① 相机是否正常
python task_VTG/scripts/save_camera_frame.py --direct

# ② 检测与手眼误差是否 < 2cm
python task_VTG/scripts/test_detect_localize.py --direct

# ③ 力控+分拣管道（不依赖视觉）
python task_VTG/scripts/run_pipeline_m3.py --direct --no-force-log

# ④ 视觉接入
python task_VTG/scripts/run_pipeline_m4.py --direct --no-force-log --seed 7

# ⑤ 录屏用标注图
python task_VTG/scripts/annotate_frame.py --direct --seed 7

# ⑥ 进阶抗干扰
python task_VTG/scripts/run_retrack_demo.py --direct --retrack --nudge --no-force-log
```

## 5. 关键模块（不是入口，但会被调用）

| 路径 | 职责 |
|------|------|
| `config.py` | 放置区、HOME、随机范围、颜色↔软硬、RETRACK 阈值 |
| `pipeline.py` | 状态机编排（`source=config` / `vision`） |
| `vision/camera.py` | Eye-to-Hand 取 RGB-D |
| `vision/detect.py` | HSV 红/黄 → 相机系 3D |
| `vision/handeye.py` | 相机系 → 基座系 |
| `vision/targets.py` | 拼成流水线待抓列表 |
| `vision/annotate.py` | Demo 画面文字/框 |
| `grasp/adaptive_bridge.py` | **唯一**推荐的力控入口（内部 load B2） |
| `motion/approach.py` | 预热、分段接近、重跟踪接近 |
| `motion/retreat.py` | 抬清、回 HOME |
| `sort/place_zones.py` | 进区判定 |
| `tracking/retrack.py` | `maybe_retrack` |

库函数请通过脚本入口调用；直接 `import` 时需已把 `task_VTG` 与 `task_B2` 加入 `sys.path`（各脚本开头已处理）。

## 7. 常见问题

**Q：报错找不到 `utils.robot`？**  
A：必须在仓库根目录运行；不要 `cd task_VTG` 再跑相对错误路径。

**Q：检测为 0 / `detect_miss`？**  
A：确认物体已染红/黄；臂是否挡住顶视（应先回 HOME）；先跑 M2 看 overlay。

**Q：M4 很慢？**  
A：加 `--direct --no-force-log`；GUI 模式会更慢。

**Q：只想看图不想抓？**  
A：用 `annotate_frame.py` 或 `save_camera_frame.py`。

**Q：和任务 B2 什么关系？**  
A：VTG 负责「看见 + 编排 + 分拣」；**抓紧力度**全部走 B2 自适应力控，经 `adaptive_bridge` 调用，不复制 PID。
